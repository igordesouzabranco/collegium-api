Collegium API

API REST de gestão universitária de faculdade — Node.js, Express 5, Sequelize 6 e MariaDB/TiDB. Cadastros de cursos, turmas, disciplinas, professores e alunos, com avaliações, notas, chamadas e boletim.

verificando… v1.0.0 99 requests no Insomnia MIT

Começar em 3 passos

1. Obtenha o token com um dos contas de teste:

POST /tokens
{ "email": "john.doe@example.com", "password": "123456" }

2. Use-o no cabeçalho das demais requisições:

Authorization: Bearer <token>

3. Explore os recursos — rotas, filtros e rotas em lote.

Rotas em lote (tudo ou nada)

      
Roda dentro de uma transação: se algum item violar a regra,
        nada é gravado. Chamada repetida no mesmo dia ou nota já
        existente devolve 409.

      
POST /turmas/{id}/chamada

      
{ "data": "2026-10-05", "presencas": [{ "alunoId": 1, "presente": true }] }

      
POST /avaliacoes/{id}/notas/lote

      
{ "notas": [{ "alunoId": 1, "valor": 8.5 }] }

    


    

      
Erros

      
Sempre no formato:

      
{ "errors": ["mensagem em português"] }

      

        
StatusQuando

        
          
200 / 201 / 204sucesso (POST devolve 201, DELETE devolve 204)

          
400violação de regra de negócio ou corpo inválido

          
401sem token, token inválido ou credenciais inválidas

          
403perfil sem permissão para escrever

          
404registro inexistente

          
409e-mail duplicado, registro já existente ou vínculo impede a exclusão
